FIR Filters &
Frequency Response
A few coefficients $b_0, \ldots, b_M$ define an LTI system. Feed it a sinusoid — out comes the same sinusoid, scaled and phase-shifted by $H(e^{j\omega})$.
Reading · §4.2.2, §4.3, §4.4
Lecture 21Objectives
By the end of this lecture you will

Read off the frequency response
of an FIR filter.

  1. Recognise the FIR input-output relationship $y[n] = \sum_{k=0}^{M} b_k\, x[n-k]$.
  2. Derive the frequency response $H(e^{j\omega}) = \sum_k b_k\, e^{-j\omega k}$.
  3. Extract amplitude $|H(e^{j\omega})|$ and phase $\angle H(e^{j\omega})$, especially for symmetric $b$.
  4. Compute $H$ at $N$ uniformly spaced frequencies by taking fft(b, N).

ConceptFIR Input-Output
FIR filter

A weighted moving sum
over $M+1$ recent samples.

$$y[n] \,=\, \sum_{k=0}^{M} b_k\, x[n-k]$$

$b = (b_0, b_1, \ldots, b_M)^{\top}$ — the coefficient vector.

Linear: superposition holds.
Time-invariant: delay in ⇒ same delay out.

ConceptENES-222 · L21
ConceptComplex Exponentials Are Eigenfunctions
Sinusoid in, sinusoid out

$x[n] = e^{j\omega n} \,\Rightarrow\, y[n] = H(e^{j\omega})\, e^{j\omega n}$.

$$H(e^{j\omega}) \,=\, b_0 + b_1\, e^{-j\omega} + \cdots + b_M\, e^{-j M\omega}$$

The output is the same complex sinusoid, scaled by the complex factor $H(e^{j\omega})$.

$H$ depends on $\omega$ only — that's the entire fingerprint of the filter at sinusoidal inputs.

System function — anywhere in $\mathbb{C}$
$$H(z) \,=\, b_0 + b_1\, z^{-1} + \cdots + b_M\, z^{-M}$$

$H(e^{j\omega})$ is just $H(z)$ restricted to the unit circle.

ConceptENES-222 · L21
Worked Example$b = (1, 2, 2, 1)^{\top}$
Worked example

Symmetric coefficients ⇒
linear phase.

Factor out $e^{-j 3\omega/2}$:

$$H(e^{j\omega}) \,=\, e^{-j 3\omega/2}\big(4\cos(\omega/2) + 2\cos(3\omega/2)\big)$$
Amplitude response
$$|H(e^{j\omega})| \,=\, |4\cos(\omega/2) + 2\cos(3\omega/2)|$$

Symmetric about $\omega = \pi$. Three zeros in $[0, 2\pi)$: at $2\pi/3$, $\pi$, $4\pi/3$.

Phase response
$$\angle H(e^{j\omega}) \,=\, -\tfrac{3\omega}{2} + (0 \text{ or } \pi)$$

Piecewise linear with $\pi$ jumps wherever the real factor changes sign.

ConceptSymmetry of $H$
Real coefficients

$|H|$ even, $\angle H$ odd
about $\omega = 0$ and $\pi$.

$$H(e^{-j\omega}) \,=\, H^{*}(e^{j\omega})$$

Just like the DFT of a real signal. So we only need to plot $H$ over $[0, \pi]$.

And $H(e^{j(\omega + 2\pi)}) = H(e^{j\omega})$ — period $2\pi$, automatic.

ConceptSample $H$ via FFT
Computing $H$ on a grid

$\mathtt{fft(b, N)}$ samples $H(e^{j\omega})$
at $N$ equally spaced frequencies.

$$H(e^{j\,2\pi k/N}) \,=\, [\mathrm{DFT}\ \text{of}\ (b;\, 0_{N-M-1})][k]$$

Pad $b$ with zeros to length $N \geq M+1$, then DFT.

For smooth plots, take $N \gg M$ — zero-padding is interpolation here too.

H = fft(b, 512);
A = abs(H); q = angle(H);

PracticeExponential Inputs
Practice

Verify three input–output pairs.

Filter
$$H(z) = 1 + 2z^{-1} + 2z^{-2} + z^{-3}$$
  • $x[n] = 3^{n} \;\Rightarrow\; y[n] = ?\,\cdot 3^{n}$
  • $x[n] = (-3)^{n} \;\Rightarrow\; y[n] = ?\,\cdot (-3)^{n}$
  • $x[n] = (1/3)^{n} \;\Rightarrow\; y[n] = ?\,\cdot (1/3)^{n}$
PracticeENES-222 · L21
SolutionJust Evaluate $H(z)$
$z = 3$
$$H(3) = 1 + \tfrac{2}{3} + \tfrac{2}{9} + \tfrac{1}{27} = \tfrac{52}{27}$$ $$y[n] = \tfrac{52}{27}\cdot 3^{n}$$
$z = -3$
$$H(-3) = 1 - \tfrac{2}{3} + \tfrac{2}{9} - \tfrac{1}{27} = \tfrac{14}{27}$$ $$y[n] = \tfrac{14}{27}\cdot (-3)^{n}$$
$z = 1/3$
$$H(1/3) = 1 + 6 + 18 + 27 = 52$$ $$y[n] = 52\cdot (1/3)^{n}$$
Lesson

$H(z)$ delivers the response to any exponential — real or complex, growing or decaying. Plug in $z$, multiply.
