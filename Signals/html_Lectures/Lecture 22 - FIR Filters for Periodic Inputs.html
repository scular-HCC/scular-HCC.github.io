Periodic Inputs
& Cascaded Filters
Periodic in, periodic out. The DFT of the output is the DFT of the input multiplied by samples of the frequency response. Cascade ⇒ multiply system functions.
Reading · §4.4.2, §4.4.4, §4.4.5
Lecture 22Objectives
By the end of this lecture you will

Predict the steady-state output
of an FIR filter.

  1. Apply $A\cos(\omega_0 n + \phi) \to |H(e^{j\omega_0})|\,A\cos(\omega_0 n + \phi + \angle H(e^{j\omega_0}))$.
  2. Extend to oscillating exponentials $r^{n}\cos(\omega_0 n + \phi)$ via $z = r e^{j\omega_0}$.
  3. Filter a periodic input with the DFT: $Y[k] = H(e^{j k\,2\pi/L})\, X[k]$.
  4. Cascade two FIR filters: $H(z) = H_1(z)\, H_2(z)$.

ConceptReal Sinusoidal Inputs
Real sinusoid in

Same frequency out —
scaled and phase-shifted.

$$x[n] = \cos(\omega_0 n + \phi) \;\Rightarrow\; y[n] = |H(e^{j\omega_0})|\,\cos\!\big(\omega_0 n + \phi + \angle H(e^{j\omega_0})\big)$$

The amplitude response scales it. The phase response shifts it. Frequency is preserved — that's why FIR filters are frequency-selective.

ConceptOscillating Exponentials
Damped sinusoid

$r^{n}\cos(\omega_0 n + \phi)$ — same shape,
evaluated at $z = r e^{j\omega_0}$.

$$y[n] \,=\, |H(r e^{j\omega_0})|\, r^{n}\cos\!\big(\omega_0 n + \phi + \angle H(r e^{j\omega_0})\big)$$

Reduces to the previous slide when $r = 1$. For $r < 1$ the input decays; for $r > 1$ it grows.

Worked ExampleDamped Cosine
Worked example

$x[n] = 2^{-n}\cos(\pi n/3 + \pi/4)$.

Filter from L21: $H(z) = 1 + 2 z^{-1} + 2 z^{-2} + z^{-3}$.

Evaluate at $z = \tfrac{1}{2}\,e^{j\pi/3}$.

$H$ at the point
$$H(z) = 1 + 4 e^{-j\pi/3} + 8 e^{-j 2\pi/3} + 8 e^{-j\pi}$$ $$|H(z)| = 13.748,\;\; \angle H(z) = -2.285$$
Output
$$y[n] \,=\, 13.748 \cdot 2^{-n}\cos\!\big(\tfrac{\pi n}{3} - 1.499\big)$$

Phase shifted by $-2.285$ on top of the original $\pi/4 = 0.785$ — net $-1.499$ rad.

ConceptPeriodic Inputs via DFT
Periodic in, periodic out

Multiply DFTs.

$$Y[k] \,=\, H\!\big(e^{j k\,2\pi/L}\big)\, X[k],\;\; k = 0, \ldots, L-1$$

Period $L$ of input ⇒ period $L$ of output (transient ignored). Compute the DFT of $x[0:L-1]$, multiply pointwise by the sampled frequency response, inverse-DFT.

X = fft(x); H = fft(b, L); Y = H .* X; y = ifft(Y);

PracticePeriod of a Three-Cosine Sum
Practice

Find $L$ for the DT input.

Signal
$$x[n] = A_1\cos(2\pi f_1 n + \phi_1) + A_2\cos(2\pi f_2 n + \phi_2) + A_3\cos(2\pi f_3 n + \phi_3)$$ $$f_1 = \tfrac{1}{8},\;\; f_2 = \tfrac{3}{20},\;\; f_3 = \tfrac{5}{12}$$
  • For each $f_i$, find the period $L_i = 1/f_i$.
  • $L$ is the LCM of the three.
PracticeENES-222 · L22
Solution$L = 120$
Individual periods

$L_1 = 8$, $L_2 = 20$, $L_3 = 12$.

LCM
$$L \,=\, \mathrm{lcm}(8, 20, 12) \,=\, 120$$
Spectral picture

Three frequencies ⇒ six nonzero DFT bins out of $120$. Each cosine becomes a complex-conjugate pair $(k, L-k)$.

DT factoid: a finite sum of periodic DT signals is always periodic. Not true in CT.

Worked ExampleFilter a Length-4 Input
Worked example

Length-4 periodic input.

Filter: $y[n] = x[n] - 4 x[n-1] + x[n-2]$, so $b = (1, -4, 1)^{\top}$.

$$x[0:3] = (2, 1, -3, 5)^{\top}$$
Procedure

X = fft(x);
H = fft(b, 4);
Y = H .* X;
y = ifft(Y);

Why this works

Pointwise multiplication of length-4 DFTs ⇔ circular convolution in time. For an $L$-periodic input the steady-state output coincides with the circular convolution of one period.

ConceptCascade of Filters
Cascade

$H(z) = H_1(z)\, H_2(z)$.
Order doesn't matter.

$$H(z) \,=\, H_1(z)\, H_2(z) \,=\, H_2(z)\, H_1(z)$$

Two FIR filters in series ⇒ one combined FIR filter. The combined coefficient vector is the linear convolution of the two coefficient vectors.

Recovery of the L08 fact: $AB \neq BA$ in general — but for LTI single-input single-output filters, $H_1 H_2 = H_2 H_1$ because complex multiplication is commutative.

Worked ExampleCascade of Two FIRs
Worked example

Multiply the system functions.

$$b^{(1)} = (1, 2, 2, 1)^{\top},\;\; b^{(2)} = (1, -4, 1)^{\top}$$
Product
$$H(z) \,=\, (1 + 2 z^{-1} + 2 z^{-2} + z^{-3})(1 - 4 z^{-1} + z^{-2})$$ $$=\, 1 - 2 z^{-1} - 5 z^{-2} - 5 z^{-3} - 2 z^{-4} + z^{-5}$$
Cascade I/O
$$y[n] = x[n] - 2 x[n-1] - 5 x[n-2] - 5 x[n-3] - 2 x[n-4] + x[n-5]$$

Lecture 22Summary
Take with you

Four facts.

01 · SINUSOIDAL
$y[n] = |H|\,A\cos(\omega n + \phi + \angle H)$
Same frequency, scaled and shifted.
02 · DAMPED
$z = r e^{j\omega_0}$ for $r^{n}$ inputs.
$H(z)$ replaces $H(e^{j\omega})$.
03 · PERIODIC
$Y[k] = H(e^{j 2\pi k/L})\, X[k]$
Multiply DFTs; inverse.
04 · CASCADE
$H(z) = H_1(z)\, H_2(z)$
Order-independent.
