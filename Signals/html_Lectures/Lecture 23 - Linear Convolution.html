Linear Convolution

The impulse response $h[n]$ characterises an LTI system completely. The output is $y = h * x$ — a true (non-circular) convolution sum.

ConceptImpulse Response
Universal characterization

One signal — $h[n]$ — defines
the entire LTI system.

$$x[n] = \delta[n] \;\Rightarrow\; y[n] = h[n]$$
$$y[n] \,=\, \sum_{k=-\infty}^{\infty} h[k]\, x[n-k] \,=\, (h * x)[n]$$

For an FIR filter with coefficients $b_0, \ldots, b_M$, $h[n] = b_n$ for $n = 0:M$, zero otherwise.

Convolution is commutative: $h * x = x * h$.

ConceptENES-222 · L23
ConceptFlip, Shift, Dot
Computing one output sample

$y[n]$ = dot product of $h$
with a flipped & shifted $x$.

  1. Reverse $x$ in time: $\tilde{x}[k] = x[-k]$.
  2. Delay by $n$: $\tilde{x}[k - n] = x[n - k]$.
  3. Dot-product with $h$: $y[n] = \sum_k h[k]\, x[n-k]$.

Repeat for every $n$.

Worked example

$b * x$ for length-4 vectors.

$$b = (2, -1, 1, -2)^{\top}$$ $$x = (1, 2, 3, -1)^{\top}$$

Output has length $K + L - 1 = 7$.

Result
$$b * x \,=\, (2,\, 3,\, 5,\, -5,\, 0,\, -7,\, 2)^{\top}$$
Spot check
$$y[0] = b_0 x_0 = 2\cdot 1 = 2$$ $$y[1] = b_0 x_1 + b_1 x_0 = 2\cdot 2 + (-1)\cdot 1 = 3$$ $$y[6] = b_3 x_3 = (-2)\cdot(-1) = 2$$

ConceptOutput Length
Length of $h * x$

$h$ of length $K$, $x$ of length $L$
⇒ output of length $K + L - 1$.

$$\text{activity interval: } [0,\, K + L - 2]$$

The first output occurs as soon as $h$ and $x$ overlap; the last occurs just before they separate.

This formula tells you how much to zero-pad before using a circular convolution.

ConceptConvolve via Padded DFT
Trick

Linear $\to$ circular —
just zero-pad enough.

$$b * s \,=\, [b;\, 0_{L-1}] \,\circledast\, [s;\, 0_{K-1}]$$

Pad each vector to length $K + L - 1$ (or more). The circular convolution of the padded vectors equals the linear convolution of the originals.

B = fft(b, K+L-1); S = fft(s, K+L-1); y = ifft(B .* S);

ConceptBlock Convolution
Long inputs, fixed-size FFTs

Split, convolve each block,
add overlapping tails.

$$b * [s^{(1)};\, s^{(2)}] \,=\, [b * s^{(1)};\, 0_{L_2}] \,+\, [0_{L_1};\, b * s^{(2)}]$$

Real-time filters use this to run with fixed-length FFTs no matter how long the input. The overlap region is where consecutive blocks' tails sum.

SolutionOverlap-Add
Solution

Overlap-add reassembles
the long output.

Block convolutions (length 9 each)
$$b * s^{(1)} = (1, -5, 6, 2, -19, -23, -2, 10, -2)^{\top}$$ $$b * s^{(2)} = (7, -16, -35, -8, -8, -9, 18, 11, -4)^{\top}$$
Combine

Pad each to length 15 and add (offset the second by 6 samples):

$$b * s = [b * s^{(1)};\, 0_{6}] + [0_{6};\, b * s^{(2)}]$$ $$=\, (1, -5, 6, 2, -19, -23, 5, -6, -37, -8, -8, -9, 18, 11, -4)^{\top}$$

Overlap region: indices 6–8 — that's where the tail of block 1 meets the head of block 2.
