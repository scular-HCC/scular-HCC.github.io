Phasors &
Discrete-Time Sinusoids
The stationary phasor compresses an entire sinusoid into one complex number. Then we jump from $t$ to $n$ — and time disappears.
Reading · Textbook §1.4 – §1.5
Lecture 04Objectives
By the end of this lecture you will

Read sinusoids as phasors,
and frequencies as angles per sample.

  1. Write $A\cos(\omega t + \phi)$ as $\Re\{A e^{j\phi}\, e^{j\omega t}\}$ — the stationary phasor is $A e^{j\phi}$.
  2. Add sinusoids of the same frequency by adding their phasors.
  3. Recognise that DT frequencies $\omega$ and $\omega + 2\pi$, or $\omega$ and $-\omega$, are equivalent — the effective range is $[0, \pi]$.
  4. Determine when a DT sinusoid is periodic: $\omega = (k/N)\,2\pi$.

ConceptStationary Phasor
Stationary phasor

One complex number
captures amplitude and phase.

$$x(t) \,=\, A\cos(\omega t + \phi) \,=\, \Re\!\left\{ A e^{j\phi} \cdot e^{j\omega t} \right\}$$
$$\text{Stationary phasor: } \;\; A e^{j\phi}$$

Think of $A e^{j\phi}$ as a snapshot of the rotating vector $z(t) = A e^{j(\omega t + \phi)}$ at $t = 0$.

The full sinusoid is the projection of that rotating vector onto the real axis.

ConceptENES-222 · L04
ConceptSum of Same-Frequency Sinusoids
Adding sinusoids

Same frequency in,
same frequency out.

$$A_1\cos(\omega t + \phi_1) + A_2\cos(\omega t + \phi_2)$$
$$= A\cos(\omega t + \phi)$$
$$\text{where }\; A e^{j\phi} \,=\, A_1 e^{j\phi_1} + A_2 e^{j\phi_2}$$

Factor out $e^{j\omega t}$ from both terms; the time-dependence drops out and what remains is a sum of phasors.

Take the real part at the end. The frequency $\omega$ never enters the algebra.

ConceptENES-222 · L04
Worked ExampleCombine via Phasors
Worked example

Combine into a single cosine.

$$2.7\cos(15\pi t + 0.6) + 4.1\sin(15\pi t - 1.8)$$
Step 1 · Convert sine to cosine
$$\sin\theta = \cos(\theta - \tfrac{\pi}{2})$$ $$4.1\sin(15\pi t - 1.8) = 4.1\cos(15\pi t - 1.8 - \tfrac{\pi}{2})$$
Step 2 · Sum the phasors
$$A e^{j\phi} = 2.7\, e^{j(0.6)} + 4.1\, e^{j(-1.8 - \pi/2)}$$
Step 3 · Read off polar form
$$A \approx 3.0241,\;\; \phi \approx 2.1937$$
Where did the sine go?

It became a phase-shifted cosine. The single phasor $A e^{j\phi}$ absorbed both contributions.

Result
$$x(t) \,=\, 3.0241\cos(15\pi t + 2.1937)$$

ConceptDiscrete-Time Sinusoid
Discrete-time sinusoid

Index $n$ counts samples.
Time is gone.

$$x[n] \,=\, A\cos(\omega n + \phi)$$
$n$
integer sample index
$\omega$
radians per sample
$A,\,\phi$
amplitude, initial phase

Seconds, Hz, periods/sec — none of it appears in this formula.

ConceptENES-222 · L04
ConventionFrequency Equivalence
Which frequencies are the same?

Mod $2\pi$. And $\omega \leftrightarrow -\omega$
for real-valued signals.

Mod $2\pi$ (complex or real)
$$e^{j(\omega + 2\pi)n} = e^{j\omega n}\, e^{j 2\pi n} = e^{j\omega n}$$
Sign flip (real only)
$$\cos(\omega n + \phi) = \cos(-\omega n - \phi)$$
Effective range for real DT sinusoids
$$\omega \in [0,\, \pi] \qquad 0 = \text{lowest (DC)},\;\; \pi = \text{highest (alternating)}$$
ConventionENES-222 · L04
Worked ExampleReduce to $[0, 2\pi)$ and $[0, \pi]$
Worked example

Find the smallest equivalent $\omega$.

Complex case
$$z[n] = e^{j(37\pi/13\, n \,+\, \pi/8)}$$

Subtract $2\pi = 26\pi/13$ from the frequency.

$$z[n] = e^{j(11\pi/13\, n \,+\, \pi/8)}$$
Real case
$$x[n] = \cos\!\left(\tfrac{42\pi}{13}\, n - \tfrac{5\pi}{6}\right)$$

Reduce mod $2\pi$: $\tfrac{42\pi}{13} - 2\pi = \tfrac{16\pi}{13}$. Then flip sign to land in $[0,\pi]$:

$$= \cos\!\left(-\tfrac{16\pi}{13}\, n + \tfrac{5\pi}{6}\right) = \cos\!\left(\tfrac{10\pi}{13}\, n + \tfrac{5\pi}{6}\right)$$

Using $\tfrac{16\pi}{13} \equiv -\tfrac{10\pi}{13}\pmod{2\pi}$.

PracticeENES-222 · L04
SolutionEndpoints of $[0, \pi]$
$\omega = 0$ — DC
$$x[n] = A\cos\phi$$

A constant sequence. Every sample takes the same value $A\cos\phi$. The signal does not oscillate at all.

$\omega = \pi$ — Nyquist
$$x[n] = A\cos(\pi n + \phi) = A(-1)^{n}\cos\phi$$

Alternating sequence: $+, -, +, -, \ldots$ — the fastest oscillation a DT sinusoid can produce.

SolutionENES-222 · L04
ConceptPeriodicity of $x[n]$
Discrete-time periodicity

Periodic only if $\omega/2\pi$
is rational.

$$\omega \,=\, \tfrac{k}{N}\,2\pi$$

The smallest $N$ for which $\omega N = 2k\pi$ holds for some integer $k$ is the fundamental period.

If $\omega/2\pi$ is irrational, $x[n]$ is aperiodic — even though it still looks oscillatory.

Beware

Unlike the continuous case, the DT period is not simply $2\pi/\omega$.

Solved Example B · §1.5.4

Find the period of
$x[n]=\cos(3\pi n/7)$.

$x[n]$ periodic iff $\omega=(k/N)\cdot2\pi$ for integers $k,N$.

Step 1 · Read $\omega$
$$\omega=3\pi/7$$
Step 2 · Solve for $N$
$$\frac{3\pi}{7}=\frac{k}{N}\cdot2\pi\implies\frac{k}{N}=\frac{3}{14}$$ Smallest integers: $k=3$, $N=14$.
Step 3 · Verify
$x[n+14]=\cos(3\pi(n+14)/7)=\cos(3\pi n/7+6\pi)=x[n]\;\checkmark$
Answer

$T_0=14$ samples.

Lecture 04Summary
Take with you

Four facts.

01 · PHASOR
$A\cos(\omega t + \phi) \leftrightarrow A e^{j\phi}$
Phasors live on $\mathbb{C}$; add them like vectors.
02 · DT SINUSOID
$x[n] = A\cos(\omega n + \phi)$
$\omega$ is radians per sample. No time.
03 · EQUIVALENCE
$\omega \equiv \omega + 2\pi$; $\omega \equiv -\omega$ (real).
Effective range: $[0, \pi]$.
04 · PERIODICITY
$\omega = (k/N)\, 2\pi$
Smallest $N$ is the fundamental period.
