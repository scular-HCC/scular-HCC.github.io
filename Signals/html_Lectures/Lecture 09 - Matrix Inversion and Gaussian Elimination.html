Matrix Inversion &
Gaussian Elimination
Solve $A\mathbf{x} = \mathbf{b}$ for any $\mathbf{b}$. Triangular matrices invert by substitution; general matrices reduce to triangular by elimination.
Lecture 09Objectives
By the end of this lecture you will

Decide whether $A$ is nonsingular,
and solve $A\mathbf{x} = \mathbf{b}$.

  1. Distinguish singular from nonsingular $n\times n$ matrices.
  2. Use the identities $A A^{-1} = I$, $(A^{\top})^{-1} = (A^{-1})^{\top}$, $(AB)^{-1} = B^{-1}A^{-1}$.
  3. Invert triangular matrices by forward or backward substitution.
  4. Apply Gaussian elimination — forward elimination, then back substitution — to a general $n\times n$ system.

ConceptWhen Does $A\mathbf{x}=\mathbf{b}$ Have a Unique Solution?
The shape of the matrix decides

Three cases for $A\,(m \times n)$.

$m < n$ · Under-determined
A solution almost always exists.
But it is not unique — input cannot be recovered.
$m > n$ · Over-determined
A random $\mathbf{b}$ almost certainly has no solution.
Most outputs are unreachable.
$m = n$ · Square
Almost certainly: every $\mathbf{b}$ has a unique $\mathbf{x}$.
$A$ is nonsingular and $\mathbf{x} = A^{-1}\mathbf{b}$.
Exception
Singular square matrices.
Some $\mathbf{b}$ have no solution; others have many.

ConceptNonsingular & the Inverse
Definition

$A$ is nonsingular iff $A\mathbf{x} = \mathbf{b}$
has a unique solution for every $\mathbf{b}$.

$$A\mathbf{x} = \mathbf{b}\;\Leftrightarrow\;\mathbf{x} = A^{-1}\mathbf{b}$$
$$A\,A^{-1} \,=\, A^{-1}\,A \,=\, I$$

The mapping $\mathbf{b} \mapsto \mathbf{x}$ is itself linear, so it has its own matrix — that's $A^{-1}$.

Permutation matrices: $P^{-1} = P^{\top}$, from last lecture's $P^{\top}P = I$.

Useful identities, each checked against the definition
$$(A^{-1})^{-1} = A \quad\text{since } A^{-1}A = AA^{-1} = I$$ $$(A^{\top})^{-1} = (A^{-1})^{\top} \quad\text{since } A^{\top}(A^{-1})^{\top} = (A^{-1}A)^{\top} = I^{\top} = I$$ $$(AB)^{-1} = B^{-1}A^{-1} \quad\text{since } (AB)(B^{-1}A^{-1}) = A(BB^{-1})A^{-1} = AA^{-1} = I$$

Worked ExampleInverse of a Product
Worked example · the order reverses

Check $(AB)^{-1}=B^{-1}A^{-1}$.

$$A=\begin{bmatrix}1&0\\2&1\end{bmatrix},\;\; B=\begin{bmatrix}1&3\\0&1\end{bmatrix}$$

Inverses: $A^{-1}=\begin{bmatrix}1&0\\-2&1\end{bmatrix}$, $B^{-1}=\begin{bmatrix}1&-3\\0&1\end{bmatrix}$ (each satisfies $MM^{-1}=I$).

Product and the claimed inverse
$$AB=\begin{bmatrix}1&3\\2&6+1\end{bmatrix}=\begin{bmatrix}1&3\\2&7\end{bmatrix},\qquad B^{-1}A^{-1}=\begin{bmatrix}1+6&-3\\-2&1\end{bmatrix}=\begin{bmatrix}7&-3\\-2&1\end{bmatrix}$$
Multiply them: should give $I$
$$(AB)\,B^{-1}A^{-1}=\begin{bmatrix}1(7)+3(-2)&1(-3)+3(1)\\2(7)+7(-2)&2(-3)+7(1)\end{bmatrix}=\begin{bmatrix}1&0\\0&1\end{bmatrix}\;\checkmark$$

Wrong order: $A^{-1}B^{-1}=\begin{bmatrix}1&-3\\-2&7\end{bmatrix}$ gives $(AB)A^{-1}B^{-1}$ first row $[-5,\,18]\neq[1,0]$.

ConceptDiagonal & Triangular Inverses
Easy cases

Diagonals invert entry by entry.
Triangles invert by substitution.

Diagonal
$$D=\mathrm{diag}(2,-3,5)\;\Rightarrow\;D^{-1}=\mathrm{diag}\!\left(\tfrac12,-\tfrac13,\tfrac15\right)$$

$\mathrm{diag}(\cdot)$ has these on the diagonal and $0$ elsewhere. Needs every $d_{ii}\neq0$. Check: $2\cdot\tfrac12=1$, $(-3)(-\tfrac13)=1$, $5\cdot\tfrac15=1$.

Triangular

Lower triangular $L$ (all entries above the diagonal are $0$): solve $L\mathbf{x}=\mathbf{b}$ by forward substitution ($x_1\to x_2\to\cdots\to x_n$). Upper triangular $U$ (all entries below the diagonal are $0$): backward substitution ($x_n\to\cdots\to x_1$).

Why every diagonal entry must be nonzero

Row $i$ of $L\mathbf{x}=\mathbf{b}$ reads $l_{i1}x_1+\cdots+l_{ii}x_i=b_i$, so $x_i=\bigl(b_i-l_{i1}x_1-\cdots-l_{i,i-1}x_{i-1}\bigr)/l_{ii}$. Each step divides by $l_{ii}$: if all are nonzero a unique $\mathbf{x}$ exists for every $\mathbf{b}$ ($L$ is nonsingular).

Worked ExampleForward Substitution
Worked example

Invert $L$ via forward substitution.

$$L = \begin{bmatrix}2 & 0 & 0 \\ 5 & -1 & 0 \\ 1 & -2 & 3\end{bmatrix}$$

Solve $L\mathbf{x}=\mathbf{b}$ for a general $\mathbf{b}=(b_1,b_2,b_3)^\top$, one row at a time.

Row 1
$$2 x_1 = b_1 \;\Rightarrow\; x_1 = \tfrac{1}{2} b_1$$
Row 2 (use the known x1)
$$5 x_1 - x_2 = b_2 \;\Rightarrow\; x_2 = 5x_1 - b_2 = \tfrac{5}{2} b_1 - b_2$$
Row 3 (use the known x1 and x2)
$$x_1 - 2 x_2 + 3 x_3 = b_3 \;\Rightarrow\; x_3 = \tfrac{1}{3}\bigl(b_3 - x_1 + 2x_2\bigr) = \tfrac13\bigl(b_3 - \tfrac12 b_1 + 5b_1 - 2b_2\bigr)$$ $$x_3 = \tfrac13\bigl(\tfrac92 b_1 - 2b_2 + b_3\bigr) = \tfrac{3}{2} b_1 - \tfrac{2}{3} b_2 + \tfrac{1}{3} b_3$$

Worked example · assemble and check
Stack into a matrix

$\mathbf{x}=L^{-1}\mathbf{b}$, so the coefficients of $b_1,b_2,b_3$ in each $x_i$ form row $i$ of $L^{-1}$:

$$L^{-1} = \begin{bmatrix}\tfrac{1}{2} & 0 & 0 \\[10pt] \tfrac{5}{2} & -1 & 0 \\[10pt] \tfrac{3}{2} & -\tfrac{2}{3} & \tfrac{1}{3}\end{bmatrix}$$
Check: rows of L times columns of its inverse give I
$$\text{row 2: }\; 5\!\cdot\!\tfrac12-1\!\cdot\!\tfrac52=0,\quad 5\!\cdot\!0-1\!\cdot\!(-1)=1,\quad 0$$ $$\text{row 3: }\; 1\!\cdot\!\tfrac12-2\!\cdot\!\tfrac52+3\!\cdot\!\tfrac32=\tfrac12-5+\tfrac92=0,\quad 2-2=0,\quad 3\!\cdot\!\tfrac13=1$$

Row 1 is $2\cdot\tfrac12=1$ and zeros. All nine entries match $I$.

ConceptGaussian Elimination
The principle

Reduce to triangular,
then back-substitute.

$$A\mathbf{x} = \mathbf{b}\;\Leftrightarrow\;(MA)\mathbf{x} = M\mathbf{b}$$

for any nonsingular $M$

Multiply by row-operation matrices until the system becomes upper triangular $U\mathbf{x} = \mathbf{c}$. Then solve by backward substitution.

Phase 1 · Forward elimination

In step $j$, use the $j$-th equation to zero out the $j$-th column below the diagonal. The denominators are the diagonal entries — the pivots.

Phase 2 · Backward substitution

Solve the resulting upper-triangular system from the bottom row up.

Worked ExampleElimination as Matrices
Worked example · what "$MA$" means

Each row operation is a matrix $E$.

Take $A=\begin{bmatrix}2&1&-1\\4&0&-1\\-8&2&3\end{bmatrix}$, $\mathbf{b}=(6,6,-10)$. Step 1 is "$R_2-2R_1$ and $R_3+4R_1$" ($R_i$ = row $i$):

Matrix for step 1, applied to $A$ and $\mathbf{b}$
$$E_1=\begin{bmatrix}1&0&0\\-2&1&0\\4&0&1\end{bmatrix},\quad E_1A=\begin{bmatrix}2&1&-1\\0&-2&1\\0&6&-1\end{bmatrix},\quad E_1\mathbf{b}=\begin{bmatrix}6\\-12+6\\24-10\end{bmatrix}=\begin{bmatrix}6\\-6\\14\end{bmatrix}$$
Matrix for step 2 ("$R_3+3R_2$"), applied to the result
$$E_2=\begin{bmatrix}1&0&0\\0&1&0\\0&3&1\end{bmatrix},\quad E_2E_1A=\begin{bmatrix}2&1&-1\\0&-2&1\\0&0&2\end{bmatrix}=U,\quad E_2E_1\mathbf{b}=\begin{bmatrix}6\\-6\\3(-6)+14\end{bmatrix}=\begin{bmatrix}6\\-6\\-4\end{bmatrix}$$

Here $M=E_2E_1$ is nonsingular, so $A\mathbf{x}=\mathbf{b}\Leftrightarrow U\mathbf{x}=M\mathbf{b}$: the same $\mathbf{x}$, an easier system.

Worked ExampleGaussian Elimination, Step 1
Worked example · step 1

Kill $x_1$ below the pivot.

$$\begin{bmatrix}2 & 1 & -1 \\ 4 & 0 & -1 \\ -8 & 2 & 3\end{bmatrix}\!\mathbf{x} = \begin{bmatrix}6 \\ 6 \\ -10\end{bmatrix}$$

Write each equation as a row $(a_{i1},a_{i2},a_{i3}\mid b_i)$. Pivot $=2$ (row 1). Multiplier $m_{i1}=a_{i1}/2$, then $R_i\leftarrow R_i-m_{i1}R_1$.

Row 2, multiplier 4/2 = 2
$$(4,0,-1\mid 6)-2(2,1,-1\mid 6)=(4,0,-1\mid 6)-(4,2,-2\mid 12)=(0,-2,1\mid -6)$$
Row 3, multiplier -8/2 = -4
$$(-8,2,3\mid -10)+4(2,1,-1\mid 6)=(-8,2,3\mid -10)+(8,4,-4\mid 24)=(0,6,-1\mid 14)$$
System after step 1
$$\begin{bmatrix}2 & 1 & -1 \\ 0 & -2 & 1 \\ 0 & 6 & -1\end{bmatrix}\!\mathbf{x} = \begin{bmatrix}6 \\ -6 \\ 14\end{bmatrix}$$

ConceptPivots Decide Singularity
Reading the pivots

One nonzero pivot per step.
That is the test.

Nonsingular

Every forward-elimination step finds a nonzero pivot (after a row swap if needed), and the last equation's $x_n$ coefficient is nonzero.

Singular

At some step every remaining equation has a zero coefficient for the current variable — or the final $x_n$ coefficient is zero.

In code: partial pivoting (swap in the largest-magnitude available pivot) keeps the procedure numerically stable even when the matrix is far from singular.

Worked ExampleA Zero Pivot and a Swap
Worked example · zero pivot

A zero pivot is not always fatal.

$$\begin{bmatrix}0&2&1\\1&1&1\\2&1&3\end{bmatrix}\mathbf{x}=\begin{bmatrix}3\\2\\1\end{bmatrix}$$
Pivot $a_{11}=0$: swap $R_1\leftrightarrow R_2$, then clear column 1
$$\left(\begin{array}{ccc|c}1&1&1&2\\0&2&1&3\\2&1&3&1\end{array}\right),\qquad R_3-2R_1:\;(2,1,3\mid1)-(2,2,2\mid4)=(0,-1,1\mid-3)$$
Pivot $2$ in row 2: multiplier $-1/2$, so $R_3+\tfrac12R_2$
$$(0,-1,1\mid-3)+\tfrac12(0,2,1\mid3)=(0,0,\tfrac32\mid-\tfrac32)$$
Back-substitute
$$\tfrac32x_3=-\tfrac32\Rightarrow x_3=-1;\quad 2x_2+x_3=3\Rightarrow x_2=2;\quad x_1+x_2+x_3=2\Rightarrow x_1=1$$

Check in the original rows: $0+4-1=3$, $1+2-1=2$, $2+2-3=1$. $\checkmark$

SolutionThree Singular $A$'s
Solution

Each $A$ has a dependent column.

A1 = zero matrix

$A_1\mathbf{x}=(0,0)$ for every $\mathbf{x}$.

No solution: $\mathbf{b}=(1,0)$ needs $0=1$.

$A_1\mathbf{x}=\mathbf{0}$ holds for $(1,0)$, $(0,1)$ and all others.

A2

$A_2\mathbf{x}=(x_1,\,0)$, so the image is the horizontal axis.

No solution: $\mathbf{b}=(0,1)$ needs $0=1$.

$A_2(0,c)=(0,0)$ for every $c$.

A3

$A_3\mathbf{x}=(x_1+3x_2)\,(1,2)$: row 2 is twice row 1.

No solution: $\mathbf{b}=(1,0)$ needs $x_1+3x_2=1$ and $2(x_1+3x_2)=0$.

$A_3(3c,-c)=(3c-3c)(1,2)=\mathbf{0}$.

Pattern

Dependent columns (one is a combination of the others): some $\mathbf{b}$ are unreachable, and $A\mathbf{x}=\mathbf{0}$ has solutions other than $\mathbf{x}=\mathbf{0}$ (the null space).

In elimination

For $A_3$: $R_2-2R_1$ gives $(0,0\mid b_2-2b_1)$, a zero pivot no row swap fixes; $b=(1,0)$ leaves $0=-2$.

Worked example · elimination finds the failure

Solve $A\mathbf{x}=\mathbf{b}$ by elimination.

$$A=\begin{bmatrix}1&2&1\\2&3&0\\0&1&2\end{bmatrix},\;\mathbf{b}=\begin{bmatrix}4\\5\\4\end{bmatrix}$$

ConceptCommon Mistakes
Check yourself

Three mistakes to avoid.

1 · $(AB)^{-1}=A^{-1}B^{-1}$

The order reverses: $(AB)^{-1}=B^{-1}A^{-1}$. In the worked example the wrong order gave first row $[-5,18]$ instead of $[1,0]$.

2 · Calling a matrix singular at the first zero pivot

Look below the zero for a nonzero entry and swap rows (our example $\left[\begin{smallmatrix}0&2&1\\1&1&1\\2&1&3\end{smallmatrix}\right]$ was nonsingular). Singular only if every candidate is zero.

3 · Forgetting earlier unknowns in substitution

In forward substitution row $i$ uses all of $x_1,\dots,x_{i-1}$, not just $x_{i-1}$ (row 3 of the $L$ example used both $x_1$ and $x_2$).

Lecture 09Summary
Take with you

Six facts about solving $A\mathbf{x}=\mathbf{b}$.

01 · NONSINGULAR
Unique $\mathbf{x}$ for every $\mathbf{b}$.
$A^{-1}$ exists; $\mathbf{x} = A^{-1}\mathbf{b}$.
02 · INVERSE RULES
$(AB)^{-1} = B^{-1}A^{-1}$
$(A^{\top})^{-1} = (A^{-1})^{\top}$.
03 · TRIANGULAR
Nonsingular iff all diagonal entries $\neq 0$.
Solve by forward / backward substitution.
04 · GAUSSIAN ELIMINATION
Forward elimination → $U\mathbf{x}=\mathbf{c}$.
Back-substitute to recover $\mathbf{x}$.
05 · PIVOTS
Exactly one nonzero pivot per step.
Otherwise $A$ is singular.
06 · WHEN STUCK
Row swap.
Records as a permutation $P$.
