ConceptThree Matrices
$P$, $R$, $F$

Shift, reverse, modulate.

$P$ · Circular shift

$Px$ moves each entry down one slot, wrapping the last to the top.

$$P^{m}: \text{shift by } m;\;\; P^{N} = I$$
$R$ · Circular reversal

$Rx$ keeps index $0$ in place and reverses the rest.

$$R^{2} = I,\;\; R^{\top} = R$$
$F$ · Modulation

$F = \mathrm{diag}(v^{(1)})$ where $v = e^{j 2\pi/N}$.

$$y = F^{k} x:\;\; y[n] = e^{j k(2\pi/N) n}\,x[n]$$

Express each $x^{(i)}$ using $P$, $R$, $F$ and $x$.

Setup
$$x = (0, 1, 2, 3, 4, 5)^{\top},\;\; N = 6$$

  • $x^{(4)} = (0,-4,-2,0,2,4)^{\top}$
  • $x^{(5)} = (0,-1,2,-3,4,-5)^{\top}$
  • $x^{(6)} = (0,2,0,6,0,10)^{\top}$

SolutionDecompositions
$x^{(1)}$ — shift up by 4 (down by $-4 \equiv 2$)
$$x^{(1)} = P^{-4} x = P^{2} x$$
$x^{(2)}$ — reflect about index 3
$$x^{(2)} = R\,P^{-1} x \;\; (\text{or}\;\; P\,R\,x)$$
$x^{(3)}$ — circularly reversed plus $x$
$$x^{(3)} = R x + x \;\; (\text{check: } R x = (0,5,4,3,2,1)^{\top})$$
$x^{(4)}$ — $x - R x$
$$x^{(4)} = x - R x$$
$x^{(5)}$ — sign-flip alternate entries
$$x^{(5)} = F^{N/2} x = F^{3} x$$

Since $F^{3}$ has diagonal $1, -1, 1, -1, \ldots$ for $N=6$.

$x^{(6)}$ — zero out even slots, double the odd ones
$$x^{(6)} = x - F^{3} x$$

$F^{3}$ has diagonal $(1,-1,1,-1,1,-1)$, so $x - F^{3} x = x\,(1-(-1)^{n})$.

ConceptSymmetry of $V$ and $W$
Circular conjugate symmetry of $V$

$V^{*} = V R = R V$,
so $W = V R$.

$$V^{*} \,=\, V R \,=\, R V$$
$$W \,=\, V^{*},\;\; V \,=\, W R \,=\, R W$$

The $k$-th and $(N-k)$-th columns of $V$ are conjugates — exactly the same property real signals exhibit in their DFTs.

$V$ is symmetric (so rows and columns share the same symmetry).

Useful identities follow: $R V R = V$ and $R W R = W$.

ConceptDFT 3 — Conjugation
DFT 3

$x^{*} \,\leftrightarrow\, R X^{*}$

$$y = x^{*} \;\Longrightarrow\; Y = R X^{*}$$

Plug into the analysis equation:

$$Y = W y = W x^{*} = R W^{*} x^{*} = R X^{*}$$

Used $W = R W^{*}$ from the conjugate symmetry of $W$.

ConceptENES-222 · L14
ConceptDFT 4 — Reversal
DFT 4

$R x \,\leftrightarrow\, R X$

$$y = R x \;\Longrightarrow\; Y = R X$$

Same idea, easier:

$$Y = W R x = R W x = R X$$

Reverse in time ⇔ reverse in frequency. No conjugates.

Worked ExampleUse DFT 3 and DFT 4
Worked example

One known pair, two free.

Given
$$x = (1,\, j,\, -2,\, 2j)^{\top}$$ $$X = (-1+3j,\, 2,\, -1-3j,\, 4)^{\top}$$
Conjugate $x$
$$x^{*} = (1, -j, -2, -2j)^{\top}$$ $$\Rightarrow Y = R X^{*} = (-1-3j,\, 4,\, -1+3j,\, 2)^{\top}$$
Reverse $x$
$$R x = (1,\, 2j,\, -2,\, j)^{\top}$$ $$\Rightarrow Y = R X = (-1+3j,\, 4,\, -1-3j,\, 2)^{\top}$$
