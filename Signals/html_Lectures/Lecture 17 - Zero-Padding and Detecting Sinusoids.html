ConceptZero-Padding Pair
Zero-padding

Pad $s$ with $N - L$ zeros
to get a length-$N$ vector $y$.

$$y = [s; 0_{N-L}]$$
$$\text{If } N = ML: \;\; S[k] = Y[kM]$$

Take every $M$-th entry of $Y$ to recover $S$. The other entries are extra samples of a denser frequency grid.

Notation

$[s; 0_{N-L}]$ is $s$ followed by $N-L$ zeros: $(1,2,-1)$, $N=5$ gives $(1,2,-1,0,0)$. $S$, $Y$ are the DFTs of $s$, $y$.

Proof, one line at a time

Start from the DFT definition of $Y$ (length $N$), evaluated at index $kM$:

$$Y[kM] = \sum_{n=0}^{N-1} y[n]\,e^{-j2\pi (kM) n/N}$$

Since $y[n] = 0$ for $n \ge L$, the sum stops at $L-1$, and $y[n]=s[n]$ there. With $N = ML$, the exponent is $\tfrac{kMn}{ML} = \tfrac{kn}{L}$:

$$Y[kM] = \sum_{n=0}^{L-1} s[n]\,e^{-j2\pi k n/L} = S[k]$$

Worked Example$L=3$, $N=12$
Worked example

Two extracted DFTs.

Setup

$a, b, c$ are any three numbers (the entries of $s$); $Y$ is the length-12 DFT of $y$.

$$y = (a, b, c, 0, 0, 0, 0, 0, 0, 0, 0, 0)^{\top}$$ $$Y = (Y_0, Y_1, \ldots, Y_{11})^{\top}$$
Length-3 DFT

$L = 3$, $N = 12$, so $M = N/L = 4$ and $Y[4k] = S[k]$.

$$(a, b, c)^{\top} \,\leftrightarrow\, (Y_0,\, Y_4,\, Y_8)^{\top}\quad (k=0,1,2)$$
Length-4 DFT

Appending one more zero does not change $y$: it is also $(a,b,c,0)^{\top}$ padded to 12. Now $L=4$, $M = 12/4 = 3$:

$$(a, b, c, 0)^{\top} \,\leftrightarrow\, (Y_0,\, Y_3,\, Y_6,\, Y_9)^{\top}\quad (k=0,1,2,3)$$
Numerical check with a=1, b=2, c=-1

$S[1] = 1 + 2e^{-j2\pi/3} - e^{-j4\pi/3} = 1 + (-1 - j\sqrt3) - (-\tfrac12 + j\tfrac{\sqrt3}{2}) = 0.5 - j\,2.598 = Y_4$.

Length-4: $1 + 2e^{-j\pi/2} - e^{-j\pi} = 1 - 2j + 1 = 2 - 2j = Y_3$.

Solved Example A · zero-padding by hand

Zero-pad $\mathbf{s}=(1,2,-1)^\top$ to $N=12$.

Find which entries of $Y$ equal $S[k]$, and compute all of $Y$.

Step 1 · DFT of s, L = 3

$S[k] = 1 + 2e^{-j2\pi k/3} - e^{-j4\pi k/3}$, with $e^{-j2\pi/3} = -\tfrac12 - j\tfrac{\sqrt3}{2}$, $e^{-j4\pi/3} = -\tfrac12 + j\tfrac{\sqrt3}{2}$, $e^{-j8\pi/3} = e^{-j2\pi/3}$:

$S[0] = 1+2-1 = 2$

$S[1] = 1 + 2(-\tfrac12 - j\tfrac{\sqrt3}{2}) - (-\tfrac12 + j\tfrac{\sqrt3}{2}) = \tfrac12 - j\tfrac{3\sqrt3}{2} = 0.5 - 2.598j$

$S[2] = 1 + 2e^{-j4\pi/3} - e^{-j2\pi/3} = \tfrac12 + j\tfrac{3\sqrt3}{2} = 0.5 + 2.598j$ (conjugate of $S[1]$, as $s$ is real)

Step 2 · Pad: N = 12 = 4L, so M = 4

$Y[4k]=S[k]$: $Y[0]=2$, $Y[4]=0.5-2.598j$, $Y[8]=0.5+2.598j$.

Key point

Entries $0, 4, 8$ reproduce $S$; the other nine interpolate between them (next slide). No new frequency information appears.

Step 3 · Evaluate the DFT

$Y[m] = 1 + 2e^{-j\pi m/6} - e^{-j\pi m/3}$ (length-12 DFT of $(1,2,-1,0,\ldots)$). For $m=1$: $e^{-j\pi/6} = 0.866 - 0.5j$ and $e^{-j\pi/3} = 0.5 - 0.866j$, so

ConceptSpectral Interpolation
Why zero-pad

More $N$ ⇒ denser frequency samples.

$$\Omega_k \,=\, k\,\tfrac{2\pi}{N}$$

Zero-padding does not add information — it interpolates the existing spectrum onto a finer grid.

For $N \gg L$, the amplitude spectrum looks almost continuous when plotted against $\Omega$.

Use it to look at the spectrum, not to gain resolution from new data.

ConceptDetecting a Sinusoid
Detecting a sinusoid

Peak in $|S|$ gives the frequency.

Samples: $s[n] = A\cos(\Omega_0 n + \phi) + \epsilon[n]$, $n = 0, \ldots, L-1$, with noise $\epsilon[n]$ and $\Omega_0 = k_0\,2\pi/L$.

Aliasing: $\Omega_0$ must lie in $[0, \pi]$ for the samples to represent the continuous sinusoid faithfully (L06).

Split the cosine

Euler: $\cos x = \tfrac12(e^{jx} + e^{-jx})$, so

$$A\cos(\Omega_0 n+\phi) = \tfrac{A}{2}e^{j\phi}e^{j\Omega_0 n} + \tfrac{A}{2}e^{-j\phi}e^{-j\Omega_0 n}$$
Read off the DFT

$e^{j\Omega_0 n} = e^{j2\pi k_0 n/L}$ is the $k_0$-th Fourier sinusoid (DFT value $L$ at $k_0$, 0 elsewhere); $e^{-j\Omega_0 n} = e^{j2\pi (L-k_0)n/L}$ is the $(L-k_0)$-th. Hence

$$S[k_0] = \tfrac{LA}{2}e^{j\phi},\quad S[L-k_0] = \tfrac{LA}{2}e^{-j\phi}$$ $$\Omega_0 = k_0\tfrac{2\pi}{L},\quad A = \tfrac{2|S[k_0]|}{L},\quad \phi = \angle S[k_0]$$

Noise adds a roughly flat floor; with a decent signal-to-noise ratio (signal power well above noise power) the two peaks stand out.

One DFT value tells you everything.

Given

A real sinusoid $s[n]=A\cos(\Omega_0 n+\phi)$ is sampled for $L=16$ points. Its DFT has a peak at $k_0=3$ with

$$S[3]=16.97+16.97j$$

$\angle z$ is the angle (phase) of $z=a+jb$ from the positive real axis, e.g. $\angle(1+j)=\pi/4$; $|z|=\sqrt{a^2+b^2}$ is its length.

  • Find $|S[3]|$ and $\angle S[3]$ in radians and degrees.
  • Find $A$, $\phi$ and $\Omega_0$ (rad/sample).
  • At which other bin is the mirror peak, and what is its value?
  • Check: what peak height does $LA/2$ predict?

SolutionRead Amplitude, Frequency, Phase
Solution · ≈ 5 min

$A=3$ and $\phi=\pi/4$.

Step 1 · magnitude
$$\begin{aligned}|S[3]|&=\sqrt{16.97^{2}+16.97^{2}}\\&=\sqrt{287.98+287.98}\\&=\sqrt{575.96}=24.0\end{aligned}$$
Step 2 · angle
Real and imaginary parts are equal and positive (first quadrant): $$\angle S[3]=\arctan\tfrac{16.97}{16.97}=\arctan 1=\tfrac{\pi}{4}=0.785\text{ rad}=45^{\circ}$$
Step 3 · amplitude, phase, frequency
$$\begin{aligned}A&=\tfrac{2|S[3]|}{L}=\tfrac{2(24)}{16}=3\\\phi&=\angle S[3]=\tfrac{\pi}{4}\\\Omega_0&=k_0\tfrac{2\pi}{L}=3\cdot\tfrac{2\pi}{16}=\tfrac{3\pi}{8}=1.178\text{ rad/sample}\end{aligned}$$
Step 4 · mirror bin and check
$k=L-k_0=13$ and $S[13]=\overline{S[3]}=16.97-16.97j$ (real $s$). Predicted peak $LA/2=16(3)/2=24=|S[3]|$ ✓.

Worked ExampleFrom Bin Number to Hertz
Worked example · the notebook signal

Which bin is 120 Hz?

Given

Sampling rate $f_s=1000$ Hz, $L=200$ samples, zero-padded to $N=1600$. The padded spectrum peaks at bin $k=192$.

Step 1 · bin to normalized frequency
$$\tfrac{\Omega}{2\pi}=\tfrac{k}{N}=\tfrac{192}{1600}=0.12$$
Step 2 · to rad/sample
$$\hat\Omega_0=2\pi(0.12)=0.7540\text{ rad/sample}$$
Step 3 · to hertz (L05)
Real time $t=n/f_s$, so $f=\tfrac{\Omega}{2\pi}f_s$: $$f=0.12\times1000=120\text{ Hz}$$
Step 4 · how fine and how sharp
$$\begin{aligned}\text{grid spacing}&=\tfrac{f_s}{N}=\tfrac{1000}{1600}=0.625\text{ Hz}\\\text{first null at}&\;\pm\tfrac{f_s}{L}=\pm\tfrac{1000}{200}=\pm5\text{ Hz}\end{aligned}$$

So the peak position is read to within about $0.3$ Hz, but two tones closer than about $5$ Hz would blur together (see the resolution slide).

ConceptSpectral Mainlobe: Derivation
When $\Omega_0$ is not a Fourier frequency

Sum the geometric series.

1 · Inner product

$s[n] = e^{j\Omega_0 n}$, $n=0{:}L-1$, and $v(\Omega)[n] = e^{j\Omega n}$. The inner product conjugates $v$:

$$\langle v(\Omega), s\rangle = \sum_{n=0}^{L-1} e^{j\Omega_0 n}e^{-j\Omega n} = \sum_{n=0}^{L-1} z^{n},\quad z = e^{j(\Omega_0-\Omega)}$$
2 · Geometric sum

For $z \neq 1$, $\sum_{n=0}^{L-1} z^n = \dfrac{1 - z^L}{1 - z}$. (If $z=1$, i.e. $\Omega=\Omega_0$, every term is 1 and the sum is $L$.)

3 · Factor out half-angles

Let $\theta = \Omega - \Omega_0$, so $z = e^{-j\theta}$. Use $e^{jx}-e^{-jx} = 2j\sin x$ (Euler):

$$\begin{aligned}1 - e^{-jL\theta} &= e^{-jL\theta/2}\,(e^{jL\theta/2} - e^{-jL\theta/2})\\ &= e^{-jL\theta/2}\,2j\sin\tfrac{L\theta}{2}\end{aligned}$$ $$1 - e^{-j\theta} = e^{-j\theta/2}\,2j\sin\tfrac{\theta}{2}$$

Divide; the factors $2j$ cancel and $e^{-jL\theta/2}/e^{-j\theta/2} = e^{-j(L-1)\theta/2}$:

$$\langle v(\Omega), s\rangle = e^{-j(L-1)\theta/2}\,\frac{\sin(L\theta/2)}{\sin(\theta/2)}$$
ConceptENES-222 · L17
ConceptSpectral Mainlobe
Result

The DFT samples a continuous mainlobe.

$$\langle v(\Omega), s\rangle \,=\, e^{-j(L-1)(\Omega-\Omega_0)/2}\,\frac{\sin(L(\Omega-\Omega_0)/2)}{\sin((\Omega-\Omega_0)/2)}$$
Modulus

The phase factor has $|e^{jx}| = 1$, so

$$|\langle v(\Omega),s\rangle| \,=\, \left|\frac{\sin(L(\Omega-\Omega_0)/2)}{\sin((\Omega-\Omega_0)/2)}\right|$$

Max $=L$ at $\Omega=\Omega_0$ (the $z=1$ case above).

Nulls where $\sin(L\theta/2)=0$, $\theta \ne 0$: $\theta = \pm 2\pi/L$ first. Null-to-null mainlobe width is $4\pi/L$ — longer $L$, sharper peak.

This is the Dirichlet kernel in disguise.

SolutionBetter Read-out from Padding
Solution · ≈ 5 min

Padding locates the peak.

Length-20 DFT

Fourier frequencies $f_k = k/20$. The two nearest to $0.317$ are $6/20 = 0.30$ (distance $0.017$) and $7/20 = 0.35$ (distance $0.033$). Evaluate the kernel $|\sin(L\theta/2)/\sin(\theta/2)|$ with $\theta = 2\pi(f_k - 0.317)$:

$$|S[6]| = \left|\tfrac{\sin(10\cdot 2\pi\cdot 0.017)}{\sin(\pi\cdot 0.017)}\right| = \tfrac{0.876}{0.0534} = 16.4$$ $$|S[7]| = \left|\tfrac{\sin(10\cdot 2\pi\cdot 0.033)}{\sin(\pi\cdot 0.033)}\right| = \tfrac{0.876}{0.1035} = 8.5$$

Largest is $k=6$: $f=0.30$, off by $0.017$ (true peak value is $20$).

Zero-padded to 1000

Now $f_k = k/1000$ and $0.317 \cdot 1000 = 317$ is an integer, so a grid point sits exactly at the peak: $k = 317$, $f = 0.317 = \Omega_0/2\pi$, $|Y[317]| = L = 20$. Neighbors $k=316,318$ give $19.99$.

Why

The length-20 DFT samples the continuous mainlobe at 20 points, so no sample lands on the peak. Zero-padding samples the same curve at 1000 points, close enough to find the maximum.

Mainlobe width is fixed by $L = 20$; padding does not narrow it, it only locates the maximum more precisely (worst-case error $\tfrac{1}{2N}$ in $f$).

Worked ExampleLeakage with $L=4$
Worked example · $\Omega_0$ between two bins

A frequency that is not a Fourier frequency.

Given

$s[n]=e^{j\Omega_0 n}$, $n=0,\dots,3$, with $\Omega_0=\tfrac{3\pi}{4}$. The length-4 grid is $\Omega_k=\tfrac{\pi k}{2}$, so $\Omega_0$ sits at "bin 1.5".

Step 1 · evaluate the kernel at each bin
$|S[k]|=\Big|\tfrac{\sin(4\theta_k/2)}{\sin(\theta_k/2)}\Big|$ with $\theta_k=\tfrac{\pi k}{2}-\tfrac{3\pi}{4}$: $$\begin{aligned}k=0&:\;\theta=-\tfrac{3\pi}{4},\;\tfrac{|\sin(-3\pi/2)|}{|\sin(-3\pi/8)|}=\tfrac{1}{0.9239}=1.082\\k=1&:\;\theta=-\tfrac{\pi}{4},\;\tfrac{|\sin(-\pi/2)|}{|\sin(-\pi/8)|}=\tfrac{1}{0.3827}=2.613\\k=2&:\;\theta=\tfrac{\pi}{4},\;\tfrac{1}{0.3827}=2.613\\k=3&:\;\theta=\tfrac{3\pi}{4},\;\tfrac{1}{0.9239}=1.082\end{aligned}$$
Step 2 · check with energy
Parseval for the DFT: $\sum_k|S[k]|^{2}=L\sum_n|s[n]|^{2}=4\cdot4=16$, and $2(1.082)^2+2(2.613)^2=2.34+13.66=16.0$ ✓.
Step 3 · zero-pad to N = 16
Now $\Omega_k=\tfrac{2\pi k}{16}$ and $\Omega_0=\tfrac{3\pi}{4}$ is exactly bin $k=\tfrac{3\pi/4}{2\pi/16}=6$, where $|Y[6]|=L=4$.

Every bin of the length-4 DFT is nonzero (leakage), and none is at the true peak. The blue curve on the next slide is the same kernel.

Solved ExampleSolved Example B · Detection
Solved Example B · detection by hand

Detect $\Omega_0$, short cosine.

$s[n]=\cos(0.7\pi n)$, $n=0{:}7$ ($L=8$). Zero-pad to $N=32$ ($M = 4$).

Step 1 · True peak bin

Fourier frequencies are $\Omega_k = 2\pi k/N = \pi k/16$. The true frequency sits at bin

$$k_0 = \frac{\Omega_0 N}{2\pi} = \frac{0.7\pi \cdot 32}{2\pi} = 11.2 \;\text{(not an integer)}$$
Step 2 · Nearest bin

$11$ is $0.2$ bins away; $12$ is $0.8$ away. So $k=11$:

$$\hat\Omega_0 = 11\cdot\tfrac{2\pi}{32} = 0.6875\pi$$

Error: $0.7\pi - 0.6875\pi = 0.0125\pi \approx 0.039$ rad.

Step 3 · Numerical check

Only $k \le N/2 = 16$ matter for a real cosine (the mirror peak is at $N-k$). Computed: $|Y[10]| = 3.89$, $|Y[11]| = 4.56$, $|Y[12]| = 4.12$. The maximum is at $k=11$, agreeing with Step 2. (It exceeds $L/2 = 4$ because the leakage of the mirror peak adds to it.)

Compare: no padding

$k_0 = 0.7\pi\cdot 8/(2\pi) = 2.8 \to k=3$, $\hat\Omega_0 = 3\cdot 2\pi/8 = 0.75\pi$: error $0.05\pi$, four times worse.

Resolution

Grid spacing $\Delta\Omega=2\pi/N=\pi/16$; larger $N$ means finer grid. The mainlobe width ($4\pi/L = \pi/2$) is fixed by $L$.

Common MistakesFour Ways to Lose Marks
Common mistakes

Check these before you hand in.

1 · "Padding sharpens the peak"

It only samples the same curve more densely. The width $4\pi/L$ depends on the number of real samples $L$ (left panel of the resolution slide).

2 · Dividing by N in A = 2|S|/L

Use the original length $L$, not the padded $N$. For the notebook, $2(355)/200=3.55$; with $N=1600$ you would get $0.44$.

3 · Frequency from the wrong length

A peak at padded bin $k$ means $\Omega=2\pi k/N$, not $2\pi k/L$. Bin 192 of 1600 is $0.754$ rad/sample; bin 192 of 200 would be nonsense.

4 · Using Y[kM] = S[k] when N is not ML

The shortcut needs $N=ML$ with integer $M$. For $L=3$, $N=4$ no bin of $Y$ equals an $S[k]$ except $k=0$.

Also: for a real sinusoid there are two peaks, at $k_0$ and $N-k_0$; search only $k\le N/2$.
