ConceptThe atoms of signal processing
Three numbers define a sinusoid

Amplitude. Frequency. Phase.

$$x[n] = A\,\cos(2\pi f\,n + \phi)$$
  • $A$ — amplitude (volts, pressure, ...).
  • $f$ — frequency in cycles per sample.
  • $\phi$ — phase in radians.
Real-world hook

A struck bell, a plucked guitar string, an RLC ring-down, an MRI free-induction-decay — all obey the damped sinusoid $e^{-\alpha n}\cos(2\pi f n)$. Same equation; only $\alpha$ and $f$ change.

ConceptWhy we window before the DFT
Spectral leakage

The DFT assumes the signal repeats.

Non-integer cycles in the window ⇒ the periodic extension has a jump. That jump injects energy into every DFT bin.

The Hamming window
$$w[n] = 0.54 - 0.46\cos\!\frac{2\pi n}{N-1}$$

Smooth taper to zero at both ends — kills the seam.

Same off-bin sinusoid — the Hamming window concentrates energy back at the true frequency.

Worked ExampleBell-tone / RLC ring-down
Exponentially-faded sinusoid

$y[n] = e^{-rn/N}\cos(2\pi f n)$

MATLAB
N = 256; r = 4; n = 0:N-1; e = exp(-r*n/N); y = cos(2*pi*f*n) .* e; semilogy(n, e); % log → straight line
PYTHON
N, r = 256, 4 n = np.arange(N) e = np.exp(-r*n/N) y = np.cos(2*np.pi*f*n) * e plt.semilogy(n, e) # log → straight line

Engineer's sanity check: plot the envelope on a log y-axis. Straight line = exponential decay.

PitfallsSinusoid-specific traps
Common mistakes

Five errors to avoid this week.

  1. Radians vs cycles. $\cos(2\pi f n)$ uses cycles/sample; $\cos(\omega n)$ uses rad/sample. They differ by $2\pi$.
  2. Length mismatch. hamming(N) and your sinusoid must have exactly the same length. Print length(t) first.
  3. Non-integer cycles in the window. Causes leakage. Fix with a window, or pick N to fit integer cycles.
  4. arange with float step. Use linspace when count matters.
  5. Linear-scale spectra. Sidelobes are 40–60 dB down. Always use dB.
