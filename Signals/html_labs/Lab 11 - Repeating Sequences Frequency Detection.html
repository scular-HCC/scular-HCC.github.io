ConceptTouch-Tone signaling
Dual-Tone Multi-Frequency

Each key = one row tone + one column tone.

  • Row frequencies: 697, 770, 852, 941 Hz.
  • Column frequencies: 1209, 1336, 1477 Hz.
  • Key '5' = 770 + 1336 Hz.
  • Receiver: DFT → loudest peak in each band.
Why two tones?

No single voice harmonic matches a DTMF pair — speech cannot accidentally trigger the decoder.

Receiver does a DFT, picks the loudest row tone and loudest column tone — decodes the key.

ConceptTime-varying frequency
A chirp

$x[n]=\cos(2\pi v[n])$, with $v[n]$ varying in time.

The instantaneous frequency is the derivative of the phase: $f_\text{inst}[n] = dv/dn$.
For a linear chirp, $v[n] = a n + \tfrac{b}{2N}n^2$, so $f_\text{inst}$ ramps linearly.

Zero-crossing estimate
$$Y[n] \equiv \frac{2n}{\text{halfcycles}[n]} \approx a + b\,\tfrac{n}{N}$$

Counting zero crossings gives a straight line in $Y$ vs $n/N$; polyfit recovers $(a, b)$.

SyntaxSynthesize + decode
Decode key '5'

Split spectrum at 1000 Hz, take loudest peak in each half.

MATLAB
fs = 8000; T = 0.3; t = 0:1/fs:T; tone = cos(2*pi*770*t) + cos(2*pi*1336*t); S = abs(fft(tone)); N = length(tone); k_cut = round(N*1000/fs); [~, ki] = max(S(1:k_cut)); [~, kj] = max(S(k_cut+1:floor(N/2)+1)); kj = kj + k_cut; Fi = (ki-1) * fs/N; Fj = (kj-1) * fs/N;
PYTHON
fs, T = 8000, 0.3 t = np.arange(0, T, 1/fs) tone = np.cos(2*np.pi*770*t) + np.cos(2*np.pi*1336*t) S = np.abs(np.fft.fft(tone)) N = len(tone) k_cut = round(N*1000/fs) ki = np.argmax(S[:k_cut]) kj = np.argmax(S[k_cut:N//2+1]) + k_cut Fi = ki * fs/N Fj = kj * fs/N

SyntaxSingle-bin DFT in O(N)
The algorithm in every PBX

Evaluate one DFT bin without the full FFT.

MATLAB
function p = goertzel_one(x, f, fs) N = length(x); k = round(N*f/fs); w = 2*pi*k/N; c = 2*cos(w); s1 = 0; s2 = 0; for i = 1:N sn = x(i) + c*s1 - s2; s2 = s1; s1 = sn; end p = sqrt(s2^2 + s1^2 - c*s1*s2); end
PYTHON
def goertzel_one(x, f, fs): N = len(x) k = round(N*f/fs) w = 2*np.pi*k/N c = 2*np.cos(w) s1, s2 = 0, 0 for xn in x: sn = xn + c*s1 - s2 s2, s1 = s1, sn return np.sqrt(s2**2 + s1**2 - c*s1*s2)

7 inner products for the 7 DTMF tones — orders of magnitude cheaper than an $N$-point FFT.

Range from beat frequency

Mix TX with echo → tone at $f_\text{beat} = \beta \cdot \tau$.

MATLAB
c = 3e8; T = 1e-3; B = 200e6; beta = B/T; fs = 5e6; N = round(fs*T); t = (0:N-1)/fs; R = 20; % target range (m) tau = 2*R/c; tx = cos(pi*beta*t.^2); rx = cos(pi*beta*(t-tau).^2); beat = tx .* rx; B_spec = abs(fft(beat .* hann(N).'));
PYTHON
c = 3e8; T = 1e-3 B = 200e6; beta = B/T fs = 5e6; N = int(fs*T) t = np.arange(N)/fs R = 20 # target range (m) tau = 2*R/c tx = np.cos(np.pi*beta*t**2) rx = np.cos(np.pi*beta*(t-tau)**2) beat = tx * rx B_spec = np.abs(np.fft.fft(beat * np.hanning(N)))

PitfallsFrequency-detection traps
Common mistakes

Five errors to avoid.

  1. Bin → frequency formula. $f = k F_s/N$ for Hz; $k/N$ for cycles/sample.
  2. Chirp early Y values. Few half-cycles in the denominator → noisy. Fit only on the second half.
  3. Polyfit coefficient order. NumPy/MATLAB both return highest-degree first: slope, then intercept.
  4. Goertzel detection threshold. Set it relative to running RMS, not absolute.
  5. Aliasing the chirp. Check that $\max f_\text{inst} < F_s/2$ before sampling.
