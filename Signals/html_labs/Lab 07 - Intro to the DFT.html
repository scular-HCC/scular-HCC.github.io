ConceptDefinition & intuition
The Discrete Fourier Transform

An inner product with $N$ sinusoids.

$$X[k] = \sum_{n=0}^{N-1} x[n]\,e^{-j2\pi kn/N}$$

$X[k]$ is the inner product of $x$ with a sinusoid at frequency $k/N$ cycles/sample. Large $|X[k]|$ ⇒ signal contains that frequency.

Matrix form: $X = F\mathbf x$, where $F_{kn} = e^{-j2\pi kn/N}$. Inverse: $\mathbf x = \tfrac{1}{N} F^* X$.

A real cosine of integer frequency ⇒ two spikes at $k$ and $N-k$.

ConceptThree properties you will use
Lecture-14 properties

Three rules to remember.

Orthogonality

$F^* F = N I$, so $F^{-1} = \frac{1}{N} F^*$. The DFT is unitary up to scale.

Real-signal symmetry

If $x[n]$ is real, $X[N-k] = X^*[k]$. Only $N/2+1$ bins carry information.

Circular shift ↔ linear phase

If $y[n] = x[(n-m) \bmod N]$, then $Y[k] = e^{-j2\pi km/N} X[k]$. Magnitude unchanged; phase tilts.

SyntaxCompute the DFT
Three computational routes

Built-in FFT vs explicit matrix.

MATLAB
N = 32; x = cos(2*pi*4*(0:N-1)/N); % Built-in X = fft(x); % Zero-padded (finer interp) Xz = fft(x, 1024); % Explicit matrix [k, n] = meshgrid(0:N-1); F = exp(-1i*2*pi*k.*n/N); X_mat = F * x.'; % Inverse x_back = ifft(X);
PYTHON
from numpy.fft import fft, ifft N = 32 x = np.cos(2*np.pi*4*np.arange(N)/N) # Built-in X = fft(x) # Zero-padded Xz = fft(x, 1024) # Explicit matrix k = np.arange(N).reshape(-1, 1) n = np.arange(N).reshape(1, -1) F = np.exp(-1j*2*np.pi*k*n/N) X_mat = F @ x # Inverse x_back = ifft(X)

ReferenceReading the spectrum
Convert bin index to frequency

Three units; pick the right one.

Normalized frequency (cycles/sample)

$f_k = k/N$   —   ranges $[0, 1)$ across all bins.

Frequency in Hz

$f_k = k\cdot F_s/N$   — multiply by sample rate.

Angular frequency (rad/sample)

$\omega_k = 2\pi k/N$   — what freqz returns.

Confusing any two of these is the #1 cause of wrong DFT plots.

Round-trip and orthogonality checks.

PitfallsDFT-specific traps
Common mistakes

Five errors to avoid.

  1. Bin index vs frequency. Use $k F_s/N$ for Hz, $k/N$ for cycles/sample. Never just $k$.
  2. Plotting the full spectrum for a real signal. Use only X[0..N//2]; the rest is the conjugate mirror.
  3. Confusing zero-padding with more data. Zero-pad samples the DTFT more finely but does not add information.
  4. Picking N not equal to a power of 2. Works, but radix-2 FFT is 2–5× faster — relevant in real time.
  5. Non-integer cycles in window. Causes leakage — window or pick $N$ to match.
