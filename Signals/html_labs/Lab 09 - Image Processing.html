ConceptFrom 1-D to 2-D
Separability

Transform rows, then columns.

$$\text{2D DFT: } X = F\,A\,F^T$$
$$\text{2D Haar: } C = V^T A\,V$$
Why this matters

A separable 2-D transform = a 1-D transform applied to every row, then to every column. All the 1-D math of Lab 8 carries over with one extra matrix multiply.

ConceptENES-222 · Lab 09
ConceptThe standard image-quality metric
Peak Signal-to-Noise Ratio

$\text{PSNR} = 10\log_{10}\!\dfrac{\text{MAX}^2}{\text{MSE}}$ dB

PSNR (dB)Quality
> 40Visually indistinguishable
30 – 40Minor artifacts (streaming)
20 – 30Visibly degraded
< 20Heavy blocking / ringing
The "knee" is the engineering operating point — more coefficients give little extra quality.
ConceptENES-222 · Lab 09
Syntax2-D DFT, compression, PSNR
Whole pipeline

Image → 2-D DFT → top-K → PSNR.

MATLAB
A = double(imread('cameraman.tif')); X = fft2(A); % Keep top M magnitudes [~, J] = sort(abs(X(:)), 'descend'); Y = zeros(size(X)); Y(J(1:M)) = X(J(1:M)); A_rec = real(ifft2(Y)); mse = mean((A(:) - A_rec(:)).^2); psnr = 10*log10(255^2 / mse);
PYTHON
from numpy.fft import fft2, ifft2 A = img.astype(float) X = fft2(A) # Keep top M magnitudes flat = X.flatten(order='F') J = np.argsort(np.abs(flat))[::-1][:M] Y = np.zeros_like(flat); Y[J] = flat[J] Y = Y.reshape(X.shape, order='F') A_rec = np.real(ifft2(Y)) mse = np.mean((A - A_rec)**2) psnr = 10*np.log10(255**2 / mse)

ConceptSubspace projection
If signal & noise live in different subspaces

Project onto signal. Noise vanishes.

Hard subspace projection

Keep coefficients at scales $0..L-1$ (low frequencies); zero scales $L..\log_2 N$. Works exactly when noise is band-limited to fine scales.

Donoho–Johnstone soft threshold
$$\hat c = \text{sgn}(c)\cdot\max(|c|-T, 0)$$

$T = \sigma\sqrt{2\ln N}$. Used when noise is broadband — works on real images.

ConceptENES-222 · Lab 09
Worked ExampleWavelet soft-threshold denoising
The real-world recipe

Transform → shrink → inverse-transform.

MATLAB
sigma = 0.15; T = sigma * sqrt(2*log(numel(img))); C = V' * img * V; % 2D Haar C_thr = sign(C) .* max(abs(C)-T, 0); img_dn = V * C_thr * V';
PYTHON
sigma = 0.15 T = sigma * np.sqrt(2*np.log(img.size)) C = V.T @ img @ V # 2D Haar C_thr = np.sign(C) * np.maximum(np.abs(C)-T, 0) img_dn = V @ C_thr @ V.T

This is essentially what scipy.signal.denoise_wavelet and MATLAB's wdenoise do under the hood.

Pitfalls2-D processing traps
Common mistakes

Five errors to avoid.

  1. PSNR with wrong MAX. If A is in [0,1], use peak = 1. If [0,255], peak = 255.
  2. Auto-scaled imshow. Sets vmin/vmax per image, making bad reconstructions look identical to good ones. Lock the scale.
  3. Believing infinite SNR carries over. Constructed orthogonality is unrealistic. Expect 5–15 dB from basic wavelet denoising.
  4. Forgetting the inverse transform. Compression operates in the transform domain; you must inverse-transform to see an image.
  5. Column-major vs row-major. MATLAB linear indices are column-major; use order='F' for flatten in Python.
