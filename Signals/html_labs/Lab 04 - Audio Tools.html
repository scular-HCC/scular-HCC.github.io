ObjectivesENES-222 · Lab 04
ConceptThe music of $2^{1/12}$
12 logarithmic steps per octave

$F_k = 440 \cdot 2^{k/12}$ Hz

  • A4 = 440 Hz (reference).
  • One semitone = ratio $2^{1/12}\!\approx 1.0595$.
  • Twelve semitones = exactly one octave (ratio 2).
Real-world hook

Guitar frets, piano-key spacing, and the band layout of every cellular network use the same exponential scale. Once you can synthesize one note, you can synthesize every Western melody.

ConceptENES-222 · Lab 04
ConceptThe shape of a note
Attack — Decay — Sustain — Release

The envelope distinguishes piano from organ.

$$E[n] = (1 - e^{-r_1 n/N}) \cdot e^{-r_2 n/N}$$
  • Large $r_1$: fast attack (percussion).
  • Small $r_2$: long sustain (organ).
  • Final tone: note = cos(2πfn) · E[n].
The envelope $E[n]$ shapes the sinusoid into a note that fades naturally.

Worked ExampleOne ADSR note
A4 at 440 Hz, piano-style

$F_s = 8000$, duration 0.5 s.

MATLAB
Fs = 8000; T = 0.5; N = round(T*Fs); n = 0:N-1; f = 440/Fs; env = (1-exp(-5*n/N)) .* exp(-6*n/N); note = cos(2*pi*f*n) .* env; audiowrite('A4.wav', note, Fs);
PYTHON
Fs, T = 8000, 0.5 N = round(T*Fs) n = np.arange(N) f = 440/Fs env = (1-np.exp(-5*n/N))*np.exp(-6*n/N) note = np.cos(2*np.pi*f*n)*env wavfile.write('A4.wav', Fs, np.int16(note*32767))

PitfallsAudio-specific traps
Common mistakes

Five errors to avoid.

  1. 1-based score ↔ 0-based score. MATLAB score = [1 8 13] → Python score - 1.
  2. Clipping on save. WAV needs samples in $[-1, 1]$ (float) or $[-32768, 32767]$ (int16). Scale before writing.
  3. Sample-rate mismatch. WAV written at Fs=8192, played at Fs=44100 → 5.4× faster, 2.5 octaves up.
  4. concatenate in a loop. Each call copies. Preallocate np.zeros(N_total) for long pieces.
  5. Forgetting to clip after envelope multiply. ADSR can leave residual peaks above 1.
