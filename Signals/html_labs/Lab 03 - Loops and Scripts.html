ConceptLoops vs vectorization
Use a loop only when…

Iteration depends on iteration.

  • Recurrence: IIR filter, PLL, gradient descent.
  • Parameter sweep: run independent analyses for many (r, f) pairs.
  • Complex body: branching, file I/O, conditionals.
Rule of thumb

Vectorized NumPy or MATLAB code runs ~100× faster than an equivalent Python for loop. y = x.^2 is right; for i: y(i)=x(i)^2 is wrong.

ConceptLecture 6 — Aliasing
Why sampling rate matters

Frequencies above $f_s/2$ fold back.

A continuous-time sinusoid at $f$ sampled at $f_s$ is indistinguishable from one at $f + k f_s$ for any integer $k$.

Observed (folded) frequency
$$f_\text{obs} = \bigl((f + f_s/2) \bmod f_s\bigr) - f_s/2$$
Every frequency interval of width $f_s$ maps back into the Nyquist band $[-f_s/2,\,f_s/2]$.

SyntaxFor-loop construction
Aliasing sweep — legitimate loop

Sweep $f$ from 0 to 3·$f_s$.

MATLAB
fs = 1.0; f_true = linspace(0, 3, 200); f_obs = zeros(size(f_true)); for i = 1:length(f_true) f_obs(i) = mod(f_true(i)+fs/2, fs) - fs/2; end plot(f_true, f_obs);
PYTHON
fs = 1.0 f_true = np.linspace(0, 3, 200) f_obs = [] for f in f_true: f_obs.append((f+fs/2) % fs - fs/2) plt.plot(f_true, f_obs)

SyntaxFunctions: anonymous and named
Reusable code blocks

Anonymous (one-line) and named (multi-line).

MATLAB
% Anonymous fun1 = @(x) exp(-x).*cos(4*x); % Pass a function handle m = max(fun1(-1:0.001:1)); % Named function in damped.m function y = damped(N, f, r) n = 0:N-1; y = exp(-r*n/N) .* cos(2*pi*f*n); end
PYTHON
# Anonymous (lambda) fun1 = lambda x: np.exp(-x)*np.cos(4*x) # Pass a function as object m = np.max(fun1(np.arange(-1, 1.001, 0.001))) # Named function def damped(N, f, r): n = np.arange(N) return np.exp(-r*n/N) * np.cos(2*np.pi*f*n)

Worked ExampleTime a loop vs a vector op
The 100× speedup

Square a million numbers.

MATLAB
N = 1e6; x = randn(N, 1); tic; y = zeros(size(x)); for i = 1:N y(i) = x(i)^2; end toc % slow tic; y = x.^2; toc % fast
PYTHON
import time N = 1_000_000 x = np.random.randn(N) t0 = time.time() y = [v**2 for v in x] print(time.time()-t0) # slow t0 = time.time() y = x**2 print(time.time()-t0) # fast

PitfallsFive errors this week
Common mistakes

Avoid these.

  1. Writing a loop where vector ops work. Always vectorize first; loop only on recurrences.
  2. Late binding in lambdas. Python captures variable names, not values. Use lambda x, a=a: a*x.
  3. Mutable default arguments. def f(x, lst=[]) shares one list across calls. Use None.
  4. arange with float step. Use linspace when the count matters.
  5. Counting up to N exclusive vs inclusive. MATLAB 1:N includes N. Python range(N) stops at N-1.
