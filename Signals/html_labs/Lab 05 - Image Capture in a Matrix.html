ConceptNo metaphor
Real-world hook

It's literally a matrix.

  • Grayscale MRI slice → float32 $M\times N$ array.
  • Satellite band (Landsat) → uint16 $M\times N$ array.
  • Phone camera frame → $1080\times 1920\times 3$ tensor.
Origin convention

Image: $(0,0)$ at top-left. Math: at bottom-left. Use origin='lower' when mixing.

Each cell holds one number; an MRI slice or photo is just a bigger version of this grid.
ConceptENES-222 · Lab 05
ConceptWhy $\gamma = 2.2$
Human perception is non-linear

Display systems compensate.

$$I_\text{out} = I_\text{in}^{\gamma}$$
  • $\gamma = 1$ — linear (no correction).
  • $\gamma = 2.2$ — sRGB display standard.
  • $\gamma < 1$ — darkens shadows.
  • $\gamma > 1$ — brightens highlights.

Same image, two languages

Load → threshold → gamma.

MATLAB
A = imread('cameraman.tif'); A = double(A) / 255; imshow(A); % Threshold B = A > 0.5; imshow(B); % Gamma correction G = A.^0.8; imshow(G); % Rotate, flip, transpose imshow(rot90(A)); imshow(flipud(A)); imshow(A.');

Worked Example2-tap FIR on an image
Difference of neighbors = edge

The simplest FIR filter, in 2-D.

MATLAB
% Horizontal difference → vertical edges Ex = A - circshift(A, 1, 2); % Vertical difference → horizontal edges Ey = A - circshift(A, 1, 1); % Gradient magnitude G = sqrt(Ex.^2 + Ey.^2); imshow(G, []);
PYTHON
# Horizontal difference → vertical edges Ex = A - np.roll(A, 1, axis=1) # Vertical difference → horizontal edges Ey = A - np.roll(A, 1, axis=0) # Gradient magnitude G = np.sqrt(Ex**2 + Ey**2) plt.imshow(G, cmap='gray')

PitfallsImage-specific traps
Common mistakes

Five errors to avoid.

  1. Forgetting order='F'. MATLAB reshape is column-major; NumPy default is row-major.
  2. Wrong vmin/vmax. If A is in $[0, 255]$, set vmax=255; if in $[0, 1]$, use vmax=1.
  3. Gamma on uint8 data. Convert to float first: (A/255.0)**gamma * 255.
  4. Origin confusion. Math-style plots need origin='lower' or flipud.
  5. Testing exact equality of floats. Use np.allclose(R, R.T), not R == R.T.
