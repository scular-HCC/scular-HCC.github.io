ConceptArrays are the universal DSP container
Real-world hook

Every signal is an array.

  • 1 s of CD-quality audio → 44 100 floats.
  • One 1080p image → 1920 × 1080 × 3 matrix.
  • One WiFi packet → ~20 000 complex samples.
  • A 5G OFDM symbol → 2048 complex frequency-bin loads.
Vectorization

Operate on the whole array in one statement. A NumPy / MATLAB expression like y = x.^2 runs ~100× faster than the equivalent for loop, because it dispatches to a compiled BLAS routine.

ConceptComplex Numbers in Code
Two representations

Cartesian vs polar.

$$z = x + j\,y = r\,e^{j\theta}$$
  • Magnitude: $r = |z| = \sqrt{x^2+y^2}$
  • Phase: $\theta = \angle z = \text{atan2}(y, x)$
  • Conjugate: $z^* = x - j\,y$
Imaginary-unit gotcha

MATLAB: i or j. Python: 1j only — bare j is a NameError.

Cartesian $(x, y)$ and polar $(r, \theta)$ are two addresses for the same point.

Worked ExampleLissajous Figure (3:2)
A complex vector traced in the plane

$z(t)=\cos(3t)+j\cos(2t)$ — draw it.

MATLAB
t = linspace(0, 2*pi, 1000); z = cos(3*t) + 1i*cos(2*t); plot(real(z), imag(z), 'b'); axis equal; title('Lissajous 3:2');
PYTHON
import numpy as np import matplotlib.pyplot as plt t = np.linspace(0, 2*np.pi, 1000) z = np.cos(3*t) + 1j*np.cos(2*t) plt.plot(z.real, z.imag, 'b') plt.gca().set_aspect('equal') plt.title('Lissajous 3:2')

PitfallsAvoid these in every lab
Common mistakes

Five errors that bite every semester.

  1. Off-by-one. MATLAB v(1) ↔ Python v[0]. Subtract 1 from every MATLAB index when porting.
  2. A.T on complex arrays. Plain transpose — no conjugation. Use A.conj().T for Hermitian.
  3. Bare j. Python wants 1j; bare j is a NameError.
  4. * vs @. NumPy * is element-wise; @ is matrix multiply. Both run; only the answer differs.
  5. arange with a float step. np.arange(0, 1, 0.1) may give 10 or 11 elements. Use linspace when count matters.
