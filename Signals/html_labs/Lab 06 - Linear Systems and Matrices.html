ObjectivesENES-222 · Lab 06
ConceptThe universal linear system
Real-world hook

The most-used algorithm.

  • SPICE: nodal admittance · node voltage = injected current.
  • GPS: satellite Jacobian · position correction = pseudo-range residuals.
  • Regression: design matrix · coefficients = observations.
  • Structural FEA: stiffness · displacement = force.
Rule

Never compute inv(A)*b. Always use the dedicated solver. Solvers do LU decomposition once; inv does it then multiplies by $b$ — twice the operations, more round-off error.

ConceptENES-222 · Lab 06
ConceptWhen the system loses accuracy
Condition number

$\kappa(A) = \sigma_{\max} / \sigma_{\min}$

Input errors are amplified by $\kappa$: $\dfrac{\|\Delta\mathbf x\|}{\|\mathbf x\|} \leq \kappa(A)\cdot\dfrac{\|\Delta\mathbf b\|}{\|\mathbf b\|}$. A matrix with $\kappa = 10^k$ loses about $k$ digits of float64 accuracy.

Practical thresholds

$\kappa < 10^3$: fine.   $10^3 < \kappa < 10^{10}$: degrading.   $\kappa > 10^{12}$: numerical noise.

$\kappa$ is the ratio of how much the matrix stretches its widest direction vs its narrowest.

SyntaxSolve, rank, det, cond
Same operation, two languages

Solve, check rank, measure conditioning.

MATLAB
A = rand(100); b = rand(100, 1); % Correct way x = A \ b; % Wrong way (slower, less accurate) x_bad = inv(A) * b; rank(A) det(A) cond(A)
PYTHON
A = np.random.rand(100, 100) b = np.random.rand(100) # Correct way x = np.linalg.solve(A, b) # Wrong way x_bad = np.linalg.inv(A) @ b np.linalg.matrix_rank(A) np.linalg.det(A) np.linalg.cond(A)

Worked ExampleLinear regression in 3 lines
Fit $y = m x + c$ to noisy data

Overdetermined system → lstsq.

MATLAB
x = linspace(0, 10, 40).'; y = 2*x + 1.5 + 0.8*randn(40, 1); A = [x ones(size(x))]; coeffs = A \ y; m = coeffs(1); c = coeffs(2);
PYTHON
x = np.linspace(0, 10, 40) y = 2*x + 1.5 + 0.8*np.random.randn(40) A = np.column_stack([x, np.ones_like(x)]) (m, c), *_ = np.linalg.lstsq(A, y, rcond=None)

This same operation underlies linear regression, Kalman filtering, and the warm-start step of every deep-learning optimizer.

PitfallsLinear-algebra traps
Common mistakes

Five errors to avoid.

  1. inv(A) * b when you mean A \ b. Twice the work, more error.
  2. Checking singularity by det == 0. Use cond or matrix_rank for floating-point detection.
  3. min(A) without axis. Python np.min(A) is global; pass axis=0 for per-column.
  4. Shape mismatch in lstsq. $A$ is $(m,n)$, $b$ is $(m,)$. A column-vector $(m,1)$ returns 2-D output.
  5. Comparing exact floats. Use np.allclose for symmetry / equality checks.
