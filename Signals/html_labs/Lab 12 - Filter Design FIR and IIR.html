ConceptFIR frequency response
From coefficients to spectrum

$H(e^{j\omega}) = \sum_k b_k e^{-j\omega k}$

The frequency response is the DTFT of the coefficient vector $b$. Sample it densely with fft(b, N), $N \gg \text{length}(b)$.

Linear phase

If $b_k = \pm b_{M-k}$, the phase is exactly linear → group delay $= M/2$ is constant → no waveform distortion.

Three regions every filter spec defines: passband, transition, stopband.

SyntaxDesign and evaluate a lowpass FIR
Window method vs least squares

37-tap lowpass, cutoff 0.5 (normalized).

MATLAB
% Window method b_win = fir1(36, 0.5); % Least-squares (Parks-McClellan) b_pm = firpm(36, [0 0.5 0.6 1], [1 1 0 0]); % Frequency response in dB [H, w] = freqz(b_win, 1, 1024); plot(w/pi, 20*log10(abs(H)));
PYTHON
from scipy.signal import firwin, firls, freqz # Window method b_win = firwin(37, 0.5, fs=2.0) # Least-squares b_ls = firls(37, [0, 0.5, 0.6, 1], [1, 1, 0, 0], fs=2.0) # Frequency response in dB w, H = freqz(b_win, 1, worN=1024, fs=2.0) plt.plot(w, 20*np.log10(np.abs(H)))

SyntaxCausal vs zero-phase
Two ways to apply a filter

filter (real-time) vs filtfilt (offline).

MATLAB
% Causal — delays by M/2 samples y_real = filter(b, 1, x); % Zero-phase — forward + backward y_off = filtfilt(b, 1, x); % Sample delay introduced by filter M = length(b) - 1; group_delay_samples = M/2;
PYTHON
from scipy.signal import lfilter, filtfilt # Causal — delays by M/2 samples y_real = lfilter(b, 1, x) # Zero-phase — forward + backward y_off = filtfilt(b, 1, x) M = len(b) - 1 group_delay_samples = M/2

filtfilt is only for offline processing. It requires the whole signal up front.

Worked ExamplePole-zero stability check
BIBO criterion

Stable ⇔ every pole inside the unit circle.

MATLAB
% v[n] = 0.5 v[n-1] - 0.4 v[n-2] + u[n] a = [1 -0.5 0.4]; b = [1]; p = roots(a); disp(abs(p)); % all < 1 → stable zplane(b, a); % Frequency response [H, w] = freqz(b, a, 1024); plot(w/pi, 20*log10(abs(H)));
PYTHON
from scipy.signal import freqz a = [1, -0.5, 0.4] b = [1] p = np.roots(a) print(np.abs(p)) # all < 1 → stable w, H = freqz(b, a, worN=1024) plt.plot(w/np.pi, 20*np.log10(np.abs(H)))

PitfallsFilter-design traps
Common mistakes

Five errors to avoid.

  1. Anti-symmetric $b$ for lowpass. Anti-symmetric coefficients give linear phase and a zero at $\omega = 0$ — useless for lowpass. Use symmetric.
  2. fft(b) vs freqz(b) axes. fft covers $[0, 2\pi)$; freqz returns $[0, \pi]$.
  3. IIR coefficient sign convention. SciPy uses $\sum a_k y[n-k] = \sum b_k x[n-k]$, so $v[n] = 0.5 v[n-1] - 0.4 v[n-2]$ becomes a = [1, -0.5, 0.4].
  4. filtfilt in real time. It requires the whole signal — cannot stream.
  5. Missing fs argument. firwin(M, 2000, fs=8000) and firwin(M, 0.5) are the same only if fs is consistent.
